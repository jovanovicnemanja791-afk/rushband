# Rush Band sajt

Statički sajt za GitHub Pages.

1. Napravite repozitorijum i otpremite sadržaj ovog foldera u koren (index.html, galerija.html, support.js, assets/).
2. Settings → Pages → Source: Deploy from a branch → main / (root).
3. Sajt je na https://KORISNIK.github.io/REPO/

Fotografije i video menjate u folderu `assets/`.
